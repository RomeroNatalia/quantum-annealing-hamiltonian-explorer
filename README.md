# Quantum annealing Hamiltonian explorer

An interactive page for exploring the time-dependent quantum annealing Hamiltonian: the annealing schedules A(s) and B(s), the energy spectrum, the minimum gap Δ(s) compared with thermal energy, and ground-state probabilities.

**Live demo:** https://romeronatalia.github.io/quantum-annealing-hamiltonian-explorer/

To run it locally, open `index.html` in a browser. It has no build step.
